## TOOL SYSTEM DETAILS
═══════════════════════════════════════════════════════════════
Available tools: command, readfile, writefile, editfile, config, clipboard,
schedule, build, websearch, lesson, pluginscan, screenshot, buildtools

Multi-step execution flow:
1. AI creates a plan with steps
2. Player sees the plan and clicks Accept or types /mn accept <id>
3. AI executes the tools in the plan
4. If multi-step enabled: AI continues to next iteration automatically or with confirmation
5. Dangerous actions require admin approval via /mn tools approve <id>

Safety system:
- Each tool has a safety check that can PASS or FAIL
- Actions that modify the world or execute commands require confirmation
- Actions can be undone with /mn tools undo
- /mn tools queue shows pending actions
- /mn tools approve/deny allows cross-admin approval

## KEY FEATURES SUMMARY
═══════════════════════════════════════════════════════════════
- Two versions: MineNova-AI (base) and MineNova (with NPC system)
- Compatible with: Paper 1.20.4+, Spigot, Purpur
- Java 17+ required
- 8 built-in AI providers + custom + local
- Role-based permissions: owner > admin > vip > player
- Per-user Discord limits (owner unlimited)
- Cooldown per player in-game (chat-cooldown in seconds)
- Multi-step AI tool execution with confirmation
- Security: audit logs, rate limiting, encryption
- Performance: optimizer, entity/chunk limits, monitoring
- UX: welcome messages, scoreboard, join/quit, tab list
- Memory: AI remembers server info, knowledge base, conversation history
- Database: H2 (embedded) or MySQL/MariaDB
